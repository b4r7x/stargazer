---
title: dgadd list
description: List available Diffgazer registry items.
---

## Usage

```bash
pnpm exec dgadd list
```

> **npm packages:** `@diffgazer/add` is on npm. `pnpm add -D @diffgazer/add` puts `dgadd` on `pnpm exec`, and `npx @diffgazer/add <command>` runs it without the install. Components also install without `dgadd` from the hosted registry: `npx shadcn add https://r.b4r7.dev/r/ui/<item>.json`.

## Examples

```bash
pnpm exec dgadd list
pnpm exec dgadd list --json
pnpm exec dgadd list --installed
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `--cwd <path>` | Working directory | `.` |
| `--json` | Output as JSON | `false` |
| `--installed` | Show only installed items | `false` |
| `--all` | Include hidden/internal items | `false` |

## Output

Names are shown with their install namespace:

```text
ui/button
ui/dialog
keys/navigation
keys/focus-trap
keys/focus-restore
keys/scroll-lock
```
